# Alzheimer Data Analysis

## Description
Projet d'analyse de données réalisé en L3 Biologie Santé, option Data Science. L'objectif était de générer, traiter et analyser des jeux de données sur Alzheimer, puis d'appliquer des méthodes statistiques pour interpréter les résultats.

## Équipe
Projet réalisé en duo

## Technologies utilisées
- **Python** : traitement et visualisation des données
- **Access** : gestion des jeux de données
- **R Commander (Rcmdr)** : analyse statistique

## Résultats
Cette étude a permis d'analyser l'association entre des variables cliniques, neuroanatomiques et métaboliques et la sévérité des symptômes moteurs dans un modèle simulé de la maladie de Parkinson. Les résultats montrent que certaines variables, dont l'âge et les volumes cérébraux, sont statistiquement associées au score UPDRS. Le modèle présente une capacité explicative limitée et ne permet pas d'établir de relations causales.

##  Apprentissages clés
- Génération et nettoyage de données massives
- Application de méthodes statistiques avec Rcmdr
- Visualisation et communication des résultats
- Collaboration en équipe et rigueur scientifique
